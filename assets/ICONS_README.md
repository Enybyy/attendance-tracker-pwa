# Iconos para PWA

Para que la aplicación funcione como PWA completa, necesitas agregar los siguientes iconos:

## Iconos Requeridos:
- `icon-192.png` - 192x192 píxeles
- `icon-512.png` - 512x512 píxeles

## Cómo crear los iconos:

### Opción 1: Usar un generador online
1. Visita: https://www.pwabuilder.com/imageGenerator
2. Sube un logo o imagen de 512x512 píxeles
3. Descarga los iconos generados
4. Coloca `icon-192.png` y `icon-512.png` en la carpeta `assets/`

### Opción 2: Crear manualmente
1. Crea una imagen cuadrada con tu logo/diseño
2. Redimensiona a 192x192 y 512x512 píxeles
3. Guarda como PNG en la carpeta `assets/`

## Colores sugeridos para el diseño:
- Fondo: #111827 (gris oscuro)
- Acento: #0891b2 (cian)
- Texto: #f3f4f6 (gris claro)

## Nota:
Mientras no tengas los iconos, la PWA funcionará pero mostrará iconos por defecto del navegador.
